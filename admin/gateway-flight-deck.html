Запуск Gateway

Перевіряє реальний маршрут VA server → Universal Gateway → Філармонія.
1
Спочатку підготуйте показ у стан OFF.

Підключення VA

Підтверджує реальний зв'язок VA server → Gateway → connector V5 → база Філармонії.
2
Gateway має бути ON.

Сеанс Філармонії

Новий сеанс створюється штатним редактором Філармонії в одному з двох залів. Ця панель його підхоплює автоматично.
3
Опублікований сеанс підхоплюється автоматично. Створення лишається службовою операцією.

Дозволи на сеанс

READ і HOLD перевіряють фактичний доступ VA до обраного сеансу через Gateway.
4
Оберіть сеанс.
